# 自在身材 · Zizai Shape AI

**好好吃，慢慢来。一个面向忙碌职场生活的 AI 饮食与运动陪伴助手。**

围绕“今天怎么吃”和“计划变了怎么办”，将用户画像、食堂/外卖搭配、饮品小食和运动安排放进同一份可调整的日常计划。“小自在”用温暖、务实的方式给出支持，保留用户的选择权。

`产品经理实践项目` · `可运行 MVP v0.3.0` · `Python / SQLite / DeepSeek`

> 当前交付为**本地单用户应用**，尚无公开在线体验地址。无需 API Key 即可体验本地演示；配置自己的 DeepSeek Key 后可使用 AI 生成与动态调整。下方截图均来自合成示例画像与本地演示，不代表真实模型质量或用户效果。

## 为什么做这个产品

目标用户是 25–35 岁、工作节奏较快的城市职场女性。项目从一个待验证的需求假设出发：用户可能了解一些饮食知识，却仍在食堂、外卖、加班、聚餐之间反复纠结，很难持续执行固定食谱。

因此，MVP 聚焦吃之前的选择与生活变化后的调整：给出方便找到的搭配，允许搜索、自选和替换，也允许保留咖啡、甜点与休息。是否真正降低决策负担，仍需要用户测试验证。

## 可以完成什么

**填写画像 → 查看个人策略 → 生成今日计划 → 推荐或搜索自选 → 生活有变化时查看草案 → 确认更新。**

| 场景 | 当前实现 |
| --- | --- |
| 想获得适合自己生活的安排 | 保存生活节奏、饮食来源、偏好与忌口；按规则匹配饮食、运动或作息重点 |
| 午餐不喜欢或没有推荐的菜 | A/B/C 候选、换一批、按餐食/食材搜索、分类与分页；选择后才保存 |
| 今天想点外卖 | 独立外卖入口、换批与搜索，提供常见点餐搭配；暂未接实时门店或下单接口 |
| 下午想喝咖啡或吃点甜的 | 饮品、小食按规格加入计划；有依据的能量计入概览，未知数值保留为未知 |
| 今天不需要下午茶 | 自行取消或恢复，联动营养合计，其他安排保留 |
| 原本安排游泳，临时要加班 | 展示餐食和实际运动项目的前后差异；确认后取消指定运动、保留其他安排 |
| 忙碌时需要一些支持 | “小自在”陪伴卡片与调整建议；根据真实完成标记反馈，可收起 |

## 关键产品取舍

| 设计选择 | 希望解决的问题 | 本版边界 |
| --- | --- | --- |
| 推荐 + 搜索自选 | 减少“只能接受模型答案”的限制 | 仍受当前餐食库覆盖范围约束 |
| 草案 → 前后对比 → 用户确认 | 避免一次聊天直接覆盖原安排 | 版本变化后旧草案失效；已完成餐次受保护 |
| 显示每日能量参考 | 帮助用户大致判断计划 | 计划估算不等于实际摄入；运动单列，不抵扣饮食 |
| 将饮品、甜点和休息纳入生活场景 | 提高现实可执行性 | 不使用惩罚、羞辱或补偿运动建议 |
| 陪伴反馈基于记录 | 让鼓励有依据 | 生成计划不等于执行，不推断体重与健康改善 |

## AI、数据与保存如何协作

- **程序**负责画像校验、忌口过滤、营养计算、规则检查和版本冲突保护。
- **DeepSeek**基于候选餐食与必要上下文组织计划和调整建议；输出通过结构、候选 ID 与内容检查后才进入草案/保存流程。失败会提示，保留现有计划。
- **SQLite**保存当前画像、按日期的计划、选择与完成标记、饮品小食、运动、调整快照和部分行为事件。当前只有一份活动画像，尚无多用户账户隔离或完整评测回放。
- **小自在**首页卡片由本地规则整理，不额外调用模型；AI 动态调整使用角色语气约束，仍保留用户确认。

参考库含 **80 条基础食品、46 条品牌规格资料（其中 1 条隔离）、54 组示例配方**。基础数据参考 USDA SR Legacy，品牌规格参考麦当劳中国官方页面；配方按食材计算估算值，均保留来源说明。条目数不等于餐食候选数，实际候选受餐次、场景与忌口影响。

实现采用结构化食品检索与规则过滤；未实现向量检索或复杂 Agent。[数据说明](docs/餐食库扩充说明_V2.md) · [规则与适用边界](docs/规则与数据说明.md) · [API 文档](docs/API.md)

## 本地体验

安装 Python 3.10+，在包含 `app.py` 的项目目录打开终端：

```powershell
python app.py --port 8766
```

浏览器打开 **http://127.0.0.1:8766**，保持终端运行。无需 Node.js、npm、独立数据库服务或 Python 第三方运行依赖。

1. 保持右上角“本地演示”，完成三步画像并保存。
2. 生成今日计划，体验搜索、自选、外卖、饮品及运动安排。
3. 在动态调整输入“今天加班，取消游泳，步行保留”，查看草案后决定是否确认。需先自行添加对应运动。

首次启动自动创建 `data/zizai.sqlite3`；刷新与重启后数据保留。`Ctrl+C` 停止服务。若端口已被占用，改为 `--port 8767` 并使用相同浏览器端口。不要用 Live Server 或直接双击 HTML。

需要真实 AI 时，在项目根目录复制配置：

```powershell
Copy-Item .env.example .env
```

已有 `.env` 时直接编辑，勿覆盖。在本机填写 `DEEPSEEK_API_KEY`，重启服务；在“偏好与限制”阅读并保存授权，再选择“DeepSeek AI”。Key 不进入前端，调用费用由自己的账号承担。[详细配置与排错](docs/本地运行与开发说明.md)

运行自动测试：

```powershell
python -m unittest discover -s tests -v
```

## 使用边界

这是生活方式产品原型，营养数据与阈值待专业复核，不提供医疗或减重处方。外卖为点餐示例，无真实库存、配送和下单；尚未验证长期健康效果。

个人数据库留在本机，只有选择 AI 并授权后才发送必要上下文；自由输入中的个人信息也可能被发送。源码包不含真实 `.env`、个人数据库或备份。当前无登录与多人隔离，不能直接将日常数据库公开给多人使用。[隐私与适用说明](docs/本地运行与开发说明.md)
