# 自在身材：分享试用、上线与简历展示

核对日期：2026-10-11。本项目当前为 Python + SQLite + DeepSeek 的本地单用户应用，尚未发布公网地址。

## 为什么原链接别人打不开

`http://127.0.0.1:8766` 是本机地址。别人打开这个链接时，访问的是他们自己的电脑，不会连接到你的电脑。

当前代码还明确只监听 127.0.0.1，并检查本机 Host/Origin，所以仅把链接发出去或替换成电脑的 IP，也不能直接提供远程试用。

服务必须有 Python 进程持续运行；不依赖 VS Code 本身。你现在从 VS Code 的终端启动服务，关闭该终端或按 Ctrl+C 会停止进程。也可以从系统终端运行或双击 start.bat。数据库保存的数据在服务停止后仍然存在。

## 别人怎么体验

| 方式 | 对方需要做什么 | 合适用途 |
| --- | --- | --- |
| 看截图与演示视频 | 打开材料链接 | 面试官快速了解产品与流程 |
| 本地运行源码或干净安装包 | 安装 Python、解压并运行 app.py；本地演示无需 Key，真实 AI 使用对方自己的 Key | 熟悉工具的同学、开发者试用 |

不一定上线才能分享。若希望对方点开链接直接使用完整功能，需要可远程访问且持续运行的后端，通常部署到支持 Python 的托管服务或服务器。

## 当前版上线之前要改什么

当前 profiles 表只有一份当前画像，未做登录/访客隔离，导出和删除也是本地用户全量操作。直接公开本地数据库会导致访问者互相覆盖画像和计划、看到或删除他人数据。

可以选择两个方向：

1. **求职演示版**：使用虚构示例资料，为每个访问者隔离临时会话，或明确提供固定示例的只读/交互演示。说明真实 AI 与示例数据的边界，不暴露日常个人数据库。
2. **真实用户试用版**：增加账号或访客标识，将画像、计划、历史、导出和删除全部限制在该用户范围，并配置服务器上的持久化存储、密钥与调用限额。

部署时还需要调整监听地址和允许域名，使用适合公开服务的运行方式及 HTTPS。只修改监听地址不能解决用户隔离和访问权限问题。

托管服务需要支持 Python 后端。GitHub Pages 可以发布项目介绍或静态演示，不能运行本项目的 Python API 和 SQLite 后端：[GitHub 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)。

例如 Render 提供 Python Web Service 与公开访问地址，但需按平台要求配置启动与端口：[Render Web Services](https://render.com/docs/web-services)。SQLite 若仍保存为本地文件，还需选择真正持久的存储；Render 普通服务文件系统默认不持久，持久磁盘需符合其套餐条件：[Persistent Disks](https://render.com/docs/disks)。此处仅解释部署条件，本项目尚未生成或验证任何平台的上线配置，也未选择付费套餐。

## 简历应该放什么链接

建议按阅读便利排列：**在线体验 / 演示视频 → 产品案例说明 → GitHub 源码**。没有在线版时，先用演示视频、项目说明和源码链接，也可以投递。

GitHub 仓库用于展示项目文件与说明。上传源码文件即可，不必把一个 ZIP 当成全部项目内容；干净安装包可以作为额外下载附件。仓库链接不会自动变成在线应用链接。

仓库 README 建议呈现：

1. 产品定位与目标用户：忙碌职场女性、生活场景中的饮食和运动选择。
2. 用户问题与 MVP 取舍：事前安排、替换、外卖示例、可选下午茶、动态调整、小自在陪伴。
3. 核心流程的截图或视频、PRD 和重要产品决策。
4. 实际完成的验证及限制。程序测试不能替代推荐质量、用户采纳或减脂效果评测。
5. 本地启动步骤与线上演示入口（有了真实地址再填）。

简历措辞示例：

> 自在身材｜AI 日常饮食与运动陪伴助手  
> 负责产品定位、MVP 范围与交互设计，结合 AI 辅助开发完成可运行原型；围绕餐食选择、临时加班与聚餐调整，设计用户确认机制和基于真实记录的陪伴反馈。

后续真实评测完成后，再填写样本数量、发现的问题与验证结果；不要提前写留存率提升、推荐采纳率提升或已验证的减脂效果。

## 上传与打包范围

公开源码可包含 app.py、zizai、web、data/reference、docs、tests、README 和 .env.example。检查截图使用虚构资料。

真实 `.env`、个人 `data/zizai.sqlite3`、数据库备份、个人导出 JSON 和未匿名化的用户评测资料不应包含在公开仓库或分享安装包里。当前 .gitignore 已忽略 Key 与数据库；已被 Git 跟踪的文件不会因添加忽略规则自动移除，需要在发布前核对。

本轮已准备的干净项目包不含真实 Key 和个人数据库。对方首次启动会创建自己的数据库，可先用本地演示模式体验。
