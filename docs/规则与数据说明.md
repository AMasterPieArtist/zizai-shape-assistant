# 规则与数据说明

静息能量采用 Mifflin–St Jeor：`10×kg + 6.25×cm − 5×年龄 + 性别常数`，常数男5、女-161。来源：https://pubmed.ncbi.nlm.nih.gov/2305711/ 。这是预测，不是测量。

原型活动系数按频率取1.4／1.5／1.6；维持参考中心最低1600 kcal，取整到50，范围±10%。超过3000暂停。**活动系数、最低值与范围是开发假设，未获专业评审，不是个体热量标准；不自动计算减重缺口。**

四餐分配25%／35%／10%／30%，一般食材份量按5g取整，盐、酱油、食用油等调味按0.1g取整，避免少量调味被舍为零；营养从基础食材相加，模型不能提交数值。基础护栏：在参考范围、至少1500 kcal，蛋白质≥0.8g/kg，碳水供能40%–70%，脂肪15%–40%，蔬菜≥300g。它们是宽松的原型测试护栏，不是完整营养标准，也未覆盖维生素、矿物质、纤维和钠。通过不代表个体适用。

基础数据由 `data/reference/dataset-v1.json` 经 `zizai/reference.py` 校验后导入 SQLite。当前80条基础食品直接抽取自 USDA SR Legacy CSV，保留 FDC ID、生熟状态、单位和来源链接；46条品牌规格资料来自麦当劳中国官方营养页，其中一条数据可疑，隔离待核对，45条可选，其中40条用于饮品小食、5条用于品牌主食配餐。54组示例配方为作者设计，按所列食材计算，包含43组正餐、7组早餐/加餐和4组自配饮品。详见[餐食库扩充说明](餐食库扩充说明_V2.md)。仍未完成营养专业复核；不代表门店实测配方。

品牌奶茶、蛋糕等未知项保存为 `nutrition=null`，不沿用旧原型假设范围。拿铁仅估算列明的牛奶。额外小食并未重新通过四餐规则，概览只显示已知部分，不能宣称全天营养达标。

忌口按标签过滤；燕麦单独保留小麦交叉接触风险。配料不完整的复合食品和品牌产品在用户有任何忌口时均不自动采纳。未知自由文本限制或候选不足会停止生成。无法保证门店实际配料或过敏交叉接触。新增食品应同时补充来源、重量、配料标签和测试。

特殊健康状态、未成年、当前／目标 BMI <18.5、目标速度>1kg/周、未知限制和知识库不足会停止普通规划。这些产品门槛及关键词不是全面医疗风险识别，不应被描述为安全认证。

DeepSeek 只从已过滤候选选择并给简短解释。程序验证 JSON、候选 ID、已完成餐次与部分风险文本，然后再验证四餐。结构错误最多重试一次；规则失败不保存。缺失知识不由模型编造。没有完整语义安全保证。

运动沿用原型示例 MET：步行3.8、休闲游泳6，计算 `MET×kg×小时`，19–59岁显示活动期间总能耗，不是净消耗。来源入口：https://pacompendium.com/ 。细分强度仍待核验。运动不抵扣饮食，不作为聚餐／奶茶的补偿。
