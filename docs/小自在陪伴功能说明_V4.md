# 小自在：日常陪伴教练 V4

更新日期：2026-10-11。应用 0.3.0，Prompt 1.5-xiaozizai。食品库、营养阈值及计划确认流程沿用原版本。

## 人设与体验

小自在是温暖、务实、有分寸的日常陪伴教练。理解加班、疲惫、聚餐和想喝奶茶的生活情境，先简短回应处境，再给出可执行选择，尊重用户确认。避免责备、羞耻、强制打卡、过度亲密称呼和空泛重复夸奖。

- 首页：绿色小芽角色形象、场景支持、下一步操作、最近7天日常回顾。可收起或展开，刷新/重启后保留偏好。
- 动态调整：使用“小自在”的角色名称与回复样式。DeepSeek 系统规则加入人设、语气、真实记录边界和待确认表达；本地演示文案同步调整。
- 欢迎页与侧栏：体现陪伴定位；首页移除重复的静态节奏卡片，保留饮食能量和具体安排。

## 真实记录边界

首页卡片由本地程序整理，明确标注非 AI 生成；不额外请求 DeepSeek。动态调整仍按右上角的演示/AI 模式执行，不把模板冒充成模型回复。

最近7天截至所选日期，未来日期以本机今天为统计上限。保存过计划与标记完成分别统计：3天生成过计划只说“为3天保存过安排”；3天主动标记餐次完成才说“3天留下完成标记”。不推断实际进食、运动、体重变化或健康效果，不制造连续打卡压力。

当前无账号身份，历史按完整画像快照保守匹配（授权开关除外），避免不同测试画像串用。普通画像修改也可能让旧历史不再匹配，这是单用户原型的限制，并非完善的多人身份系统。卡片收起偏好采用同样匹配方式。

画像更新但当天计划仍旧时，卡片提示先更新计划，不用旧计划冒充新画像的安排。取消下午茶时卡片尊重该选择，不自动恢复或追加饮食。

## 数据与运行

SQLite 新增 coach_preferences 表，仅保存卡片收起偏好；原有画像、计划、历史和食品数据保留。首次启动自动创建该表，不需要重建数据库。导出包含偏好，删除个人数据会同步删除。

```powershell
python "D:\github\自在身材\app.py" --port 8766
```

停止旧服务后重启，浏览器 Ctrl+F5 刷新。访问“今日计划”和“动态调整”体验。已有计划无需重新生成；只有新 AI 生成/调整使用新版 Prompt，历史结果保留原版本信息。
